# Autonomous Graphics Memory System

This repository is the bank for the Graphics Command Center (GCC) visual memory library: picture
references, palette/mood records and operating notes, all generated from the live library rather than
hand-written.

- **Live library:** https://site-d460edd452c14327949ad468417abf82.freebuff.page/
- **Search API:** `GET /api/search?q=&category=&color=&limit=100&offset=0`
- **Stats API:** `GET /api/stats`
- **Drop-in plugin:** `/gcc-plugin.js` (`GCC.configure({ apiKey })`), plus Unity, Godot, Unreal and an
offline Freebuff plugin under `plugins/`.

## Layout

- `memory/graphics/catalog.csv` — every asset: id, name, category, provider, licence, resolution,
dominant palette and source page. Regenerated by `tools/sync-bank.mjs`.
- `memory/graphics/catalog-seed.csv` — one in sixteen assets across every category, readable without
running anything.
- `memory/moods/summary.md` — mood distribution derived from the palettes.
- `memory/notes/README.md` — how scanning, licensing and regeneration work.
- `reports/library-snapshot.md` — per-category counts from the latest sync.
- `schemas/` — asset, memory and worker JSON schemas used across departments.
- `tools/sync-bank.mjs` — dependency-free fetcher.
- `ASSET_MEMORY_BANK/` — downloadable CC0 game assets (models, PBR sets, sprites, UI,
  audio, HDRIs) with their index; built by `tools/asset-bank/build-assets.mjs`.
- `.github/workflows/sync-bank.yml` — refreshes the catalogue four times a day (00:20, 07:20, 13:20,
19:20 UTC) and on manual dispatch.

## Scanning

The library ingests four stockpile passes a day at 00:30, 08:00, 14:00 and 20:00 local time, covering
humans, clothing, injury and behaviour, weapons and upgrades, ore and minerals, structures,
environments, climate, seasons, peoples and ages, textures, materials, lighting, props and reference
plates. Duplicates are rejected by provider id and by a perceptual hash distance of 3, so the same
picture is never stored twice.

## Licensing

Public domain, CC0, commercial stock and AI references are admitted. CC BY is admitted with attribution
recorded in the catalogue's `licence` column and on each asset's source page. CC BY-SA and
non-commercial licences are excluded.

Images stay on the providers' CDNs; this repository stores the reference, palette and notes rather than
duplicating binaries.

## Departments

`graphics`, `environment`, `character-ai`, `animation`, `quality-control` and `research` are described in
`schemas/worker-schema.json`; each department consumes the same asset and memory records.
